# Nova Launcher

Nova Launcher 是为 **Minecraft 1.6.4 RPG 地图《冒险者传说》**定制的启动器，提供玩家名设置、Java 选择、内存调整和游戏启动功能。

目前支持 **Windows** 与 **Apple Silicon Mac（macOS）**。

## 功能

- **启动游戏**：自动识别配套客户端，使用离线玩家名进入游戏。
- **选择 Java**：自动寻找本机已安装的 Java，显示版本与架构，也可手动选择并检测。
- **调整内存**：在设置中修改游戏可用的最大内存。
- **查看日志**：查看实时游戏日志，支持导出，便于反馈问题。
- **保存设置**：玩家名、Java 路径等设置保存在游戏目录，方便下次使用。

## 开始使用

### 1. 准备客户端

请准备《冒险者传说》配套客户端及适合当前平台的启动器。启动器不会自动下载游戏资源，需要保留客户端完整的 `.minecraft` 文件夹。

- **Windows**：将 `nova-launcher.exe` 放在与 `.minecraft` 同级的目录，并从该游戏目录启动；使用快捷方式时，将“起始位置”设为游戏目录。运行环境需要 WebView2 Runtime。
- **Apple Silicon Mac**：将完整的 `Nova Launcher.app` 与 `.minecraft`、配套的 `mac-dlls` 文件夹放在同一目录，再双击打开应用。这些文件夹应放在 `.app` 外部，无需放入应用内部。

### 2. 设置玩家名与 Java

打开“设置”，填写玩家名，在“本机 Java”列表中选择合适的 Java 并点击“选用”。如果未找到已安装的 Java，可点击“浏览”手动选择可执行文件，再点击“检测”。

配套客户端使用 **Java 8**。Apple Silicon Mac 需选择 **arm64 / aarch64 架构的 Java 8**，不能使用 Intel（x86_64）Java 代替。

### 3. 启动游戏

按需调整内存分配，回到主页点击启动按钮。设置会自动保存，无需每次重新填写。

## 使用说明

- 当前使用离线玩家名，暂不支持正版账号登录。
- 启动器面向配套客户端，不提供版本隔离；请保留客户端原有目录结构。
- 如需记录启动问题，可在“日志”页开启“启用日志采集”，然后重新启动游戏；该开关在下次启动游戏时生效。反馈问题时可附上导出的日志。
